# PARAMONT 企业交互展厅

面向横屏触摸大屏的本地前端展示系统。四个区域为公司介绍、全球布局与供应链、品牌与产品、数据分析；共享导航、双语内容、三维画质与自动展示。

## 启动

使用 Node.js 22 或更新版本与 npm。在项目根目录执行：

```sh
npm run setup
npm run build
npm run dev
```

打开 `http://127.0.0.1:5183/?quality=studio#/atlas/home` 查看最高精修档。`quality=exhibition` 为默认展厅档，`quality=fluid` 为流畅档；画质参数保留在网址中，跨场景生效。

源码当前使用相对符号链接共享资料。macOS/Linux 可直接检出；Windows 开发需启用 Git 符号链接支持。已构建静态文件不依赖符号链接，可在 Windows 展示电脑运行。

## 构建与交付

`npm run build` 依次构建产品模块、导出嵌入文件、构建主展厅。最终静态站点在 `展示应用/dist/client/`，可通过本地静态服务运行；不要直接双击 HTML 文件。`npm run preview` 可以预览构建结果。当前仓库链接是源码访问入口，不是公开在线展厅。

`npm test` 运行产品资料检查、两套应用测试和展厅内容校验。浏览器验证记录见 [首页与触摸回归记录](展示应用/docs/首页与触摸回归记录.md)。真实墙面触摸校准与持续 30 分钟运行仍需现场验收。

## 资料与范围

公司事实、品牌档案与视觉概念按内容中的来源和确认状态区分。模型、产品与分析示意不能当作真实场地、订单或分析结论。运行素材与源码保存在仓库；原始工作簿、素材收集目录、旧方案和本地测试缓存保留在本地。

本仓库不自动授予公司标志、品牌资料或第三方素材的再分发许可；相应权利与来源声明继续适用。
