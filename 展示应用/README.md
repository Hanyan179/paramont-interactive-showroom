# 企业交互展厅

现有产品是一个横屏、触摸和鼠标可操作的企业展厅。统一四个区域，首页以山形品牌装置、地球、样品工作台和数据装置形成环绕空间。

| 区域 | 路径 | 当前内容 |
|---|---|---|
| 公司介绍 | `/#/atlas/home` | 首页总览、我们是谁、协作网络、时间足迹、公司动态 |
| 工厂能力 | `/#/atlas/locations` | 全球布局、商品流向、创研、制造与市场协作空间 |
| 品牌与产品 | `/#/atlas/products` | 一套样品房中的品牌、品类、产品及款式 |
| 数据分析 | `/#/atlas/analytics` | 趋势、品类、人工智能辅助探索、产品方向 |

品牌和品类深链接 `/#/atlas/brands`、`/#/atlas/categories` 属于同一产品模块。旧 `studio`、`gallery` 实验入口保留，没有主导航入口。

## 本地运行

已有服务默认端口为 5183，优先复用。首次安装或换电脑使用兼容项目的 Node.js（运行环境）22 或以上版本：

```sh
npm ci
npm run dev:lan
```

本地访问 `http://127.0.0.1:5183/#/atlas/home`；同网段设备使用展示电脑的当前局域网地址。地址随网络变化，不写死。

当前 Mac 的系统运行环境不可用时，可用已安装的附带运行环境，不修改系统安全设置：

```sh
/Users/hansen/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node node_modules/vite/bin/vite.js --host 0.0.0.0 --port 5183 --strictPort
```

## 检查与构建

```sh
npm test
npm run check:content
npm run build
```

构建产生 `dist/client/` 静态展厅，以及现有托管模板需要的 `dist/server/index.js` 与 `dist/.openai/hosting.json`。静态展厅须通过本地 HTTP 服务打开，不能直接双击 `index.html`。现场媒体和内容本地加载；安装依赖需要网络。不要跨操作系统复制 `node_modules`。

若修改产品模块或共享背景/帧循环，先在 `../品牌融合世界` 执行：

```sh
npm run build
npm run export:module
```

然后回本目录检查并构建。导出目标为 `public/modules/product-explorer/`；只编辑模块源码，不能修改导出的哈希文件。完整源码交付要包含主应用、品牌模块、`共享组件`、`共享数据`；单独交付运行版本用构建产物。

## 展示约定

数据分析区已接入连贯的案例探索：三维工作台 → 趋势关系 → 品类矩阵 → 人工智能辅助流程 → 产品方向。主题和维度贯穿四段，资料与对应样品可往返。当前为明确标注的设计示例，内容维护与扩展见 [数据探索维护](docs/数据探索维护.md)。

默认静置 30 秒后界面渐隐，90 秒进入巡展；第一次操作恢复探索。手动阅读和影片播放保护停留。返回恢复原有选择，拖动不会误触进入。公司影像与图文统一在公司动态中，电视先切近景再打开播放器。

当前可选择中国、柬埔寨、美国三个不同业务概念空间。欧洲、澳洲的具体资料与位置仍待补充，没有作为已确认基地加入地球。商品流向不代表实际订单，数据流程不代表已接入实时分析服务。

素材继续放在 `../素材收集/`，本系统不会自动监控目录。原始文件和展示版本分别保存；维护流程是提供资料后整理双语内容和适合大屏的资源。
