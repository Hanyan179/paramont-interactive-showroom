# 企业交互展厅开发规则

## 目标与边界

- 用户当前请求定义范围。现有产品固定四区：公司介绍、工厂能力（全球布局与供应链）、品牌与产品、数据分析。
- 一个产品、两套前端运行部分：本目录负责主展厅，`../品牌融合世界` 负责嵌入产品模块。只保留一个全局系统栏；品牌、品类是产品区的内部浏览方式。
- 默认沿用已认可的界面、配色、透明原色标志、模型与业务路径。普通修复不启动概念稿、三套版式、依赖升级或架构重写。
- 旧 `studio`、`gallery` 路径和岩石素材保留，主产品不提供版式选择器。没有明确授权不删除旧入口、用户素材或共享数据。
- 当前规范集中维护本文件；架构与扩展方式见 [开发与扩展指南](docs/开发与扩展指南.md)。旧反馈已原样保存在 `docs/history/2026-09-10_整理前项目规则.md`，仅供追溯，不作为当前并行指令，不默认预读。

## 先找到正确修改层

- 四区名称、首页模型入口顺序、路由别名：`src/config/areas.js`。
- 共用加载文案：`src/config/uiCopy.js`；公司与能力正文保留在对应内容文件中。
- 自动巡展镜头和默认等待时间：`src/config/presentation.js`；计时引擎 `src/exhibitionDirector.js` 不放业务场景文案。
- 两端共用帧循环：`../共享组件/frameLoop.js`。主展厅手势分类：`src/interaction/scenePointer.js`。不要在新模型中另起循环或空闲计时器。
- 三维模型由对应工厂创建；`ConnectedScene.jsx` 组合场景、镜头和热点。新模型需提供实际轮廓、取景和可点击对象；几何、相机、热点使用同一坐标系。
- 共享环境由 `../共享组件/spaceAtmosphere.js` 提供，两端通过各自适配层接入。不要复制一套背景。
- 产品模块通信保留来源、窗口、通道和版本校验。内部浏览、款式与缩放有自己的状态，不能强行合并为公司场景的旋转逻辑。
- 新功能只增加有真实调用方的配置与模块。不设计万能插件框架，不用无效回退隐藏缺失的内容或地区。
- 数据探索的案例、图形、三维工作台与往返规则见 `docs/数据探索维护.md`。图形与屏幕共用关系配置；未核实来源不生成量化图表，未映射样品不回退到其他商品。

## 视觉与交互约定

- 横向桌面与整墙触摸展示，不纳入手机版。连续深蓝流动空间，银白、品牌蓝、玻璃和少量暖金属用于主体；保留安静阅读区域和视觉主次。
- 首页以山形品牌装置为中心，与地球、样品台、数据装置共同环绕。电视与刊物仅放在“公司介绍 → 公司动态”，属于同一新闻空间。
- 总览、选中、深入、返回逐层展示内容。取消手势教学文字；保留可见的返回、关闭、首页及键盘等价入口。
- 总览横向整圈自由旋转；内容选中后平滑到展示机位。再次拖动可观察，重选回到展示角度，返回序章恢复自由观察方向。
- 点击和拖动分离；取消、失去触摸捕获、切页时清理手势。一次拖动不能在松手时打开内容。
- 真实三维电视先切近景，再衔接影片；返回反向衔接。不能用整张生成图冒充可交互三维。
- 读取当前模型真实轮廓和界面避让区域，校验 1366×768、1920×1080、3840×2160 与较窄桌面比例，兼顾双语。
- 公司标志使用 `public/media/brand/paramont-global-original.png` 和现有显示层透明滤镜。原图保留，不换白色标志或白色底牌。

## 自动展示与资源生命周期

- 父展厅拥有唯一空闲导演：默认 30 秒静置后淡出界面、90 秒后跨区巡展。影片播放列表只控制影片，不负责跨区导航。
- 第一次输入只唤醒；按住触点、阅读、手动影片、目录与页面隐藏保护停留。自动影片不能永久阻塞巡展。
- 巡展保存并恢复访客选择、视角和浏览位置。无人运动不写回手动观察记忆。
- 隐藏或暂停的场景不调度帧、不推进时间；恢复不追赶离线时间。新资源需明确释放责任：模型的独占视频、纹理及监听器自行释放，共用场景资源由协调器统一回收。
- 品牌模块嵌入时接受父导演，独立运行才允许自己的展示控制。改共享循环需要验证两边进入、暂停、恢复。

## 内容与资料

- 公司事实以真实资料为准；官网只提供事实依据，不复制旧官网审美。
- 中国为创意、研究与研发源头；柬埔寨为制造供应链；美国为市场客户协作。欧洲、澳洲按市场区域维护，未确认城市不编造坐标或回退中国空间。
- 模型、场地、产品流和分析流程的概念性质需明确；不暗示实际客户、订单、规模或已经接入人工智能服务。
- 品牌档案不等于自有品牌，不能从原始清单推断品牌—品类关系。
- 图片、正文和影片走统一阅读器与媒体库，原始资料保留。预计阅读时间不是退出期限；附件使用浏览器原文件能力，不声称已原生渲染 Office 文件。

## 构建与验证

- 使用已有服务 `http://127.0.0.1:5183`，不要随意增加端口或停止其他服务。启动流程见 README。
- 无新增依赖需要时沿用现有 React、Vite、Three.js。保留锁文件。
- 变更后运行 `npm test`、`npm run check:content`、`npm run build`；按变更风险补实际浏览器交互验证。测试通过后无新变化不重复扩大检查。
- 改产品模块源码后，在模块目录构建并运行 `scripts/export-module.mjs`，再构建父展厅。禁止编辑导出的哈希资源。
- 保留 `.openai/hosting.json`、`worker/index.js`、`scripts/prepare-sites-build.mjs` 和托管模板测试。使用 Sites（网站工具）的现有本地构建检查流程，不因本地修改自行发布。
- 报告区分代码检查、浏览器验证、实机验收与发布。没有实际接屏记录，不能声称触摸校准、墙面观看效果或连续 30 分钟运行已经通过。

## 2026-09-11 单一场景导航与文档

- 仅 SystemBar 渲染底部场景导航，左侧区域菜单切换四区，中部按当前页面显示公司章节、地区/能力、产品浏览方式或分析阶段。映射由 src/config/navigation.js 维护；页面不再另起章节底栏与重复跨区按钮。
- 公司介绍区域入口直接回到首页总览（chapter 0），不提供独立“序章”子菜单。其余公司章节保留原有标识 1–4，不能因移除菜单项而改变内容、镜头或资料对应关系。
- 右上箭头专用于资料、文档和来源链接；进入场景用向右箭头，选择模型或筛选仅显示选中状态。没有可展开资料时不提供重复待补说明的按钮。
- 公司概览、协作网络、时间足迹使用各自文档。指定章节入口优先于旧阅读位置；切换语言和字号按章节与相对进度恢复，不能按旧像素位置生硬跳动。
- 产品子视图使用 ../共享组件/explorerViews.js，共用导航消息需验证来源、窗口、版本、导航编号及 view 与 section 的对应关系。

## 共用画质与模型精度

- 两端画质唯一源为 `../共享组件/qualityConfig.js`，解析、硬件限制和模型细分在 `renderQuality.js`，程序细纹在 `surfaceFinish.js`。维护说明见主展厅 `docs/画质与模型维护.md`。
- 默认展厅档；不要在单个渲染器重新写死像素预算、阴影分辨率或纹理过滤。配置只控制已经制作的能力，新增造型与动作必须在模型工厂实际实现。
- 画质变化保留触摸目标、相机取景、业务状态和巡展导演；不要通过增加无关模型或粒子数量伪装精细度。
- 共享画质修改后构建并导出产品模块，再构建主展厅。对比档位用地址的 quality 参数，不给访客增加系统栏。
