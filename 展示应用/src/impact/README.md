# 品牌展演

主展厅 `atlas/home` 默认进入本模块，沿用 5183 服务。资料阅读和产品探索复用现有模块；全部资产本地加载。

## 当前内容与数据源

- `content.js`：公司、全球供应链、品牌、品类、智能洞察五个主题，首页保留持续环境运动，其它主题沿用巡展与手动停留。供应链仅提供平面世界地图。
- `共享数据/featured-brands.json`：用户于 2026-09-14 确认的 12 个旗下品牌标识，来源为公司产品门户。Mane Street 的两个标识按用户截图分别展示；其他 67 条档案不据此推定归属。
- `共享数据/featured-categories.json`：儿童手工、文具、派对、玩具与游戏、美妆、综合手工六个主营方向。各项关联原档案类别编码，未建立品牌与品类的推测关系。门户数量仅保留为带日期的选取依据，不在主画面显示。
- `共享数据/business-footprint.json`：客户和供应商国家表的聚合，平面地图使用同一套覆盖、筛选与坐标。客户、供应商记录不是自有工厂。

## 展示与交互

- `BrandOverview.jsx` / `brandLayout.js` / `brandWorld.js`：12 个官方标志分成两排，上排缓慢向左、下排向右循环。共享帧循环同时更新三维标志位置与透明触摸目标；可独立拖动每排，点击聚焦，双侧返回保留流动位置。总览不重复叠加白色品牌名，标志保持官方颜色和比例。已撤掉大片白色背光，深色标志仅加贴合透明轮廓的细银蓝描边；透明触摸范围仍同步跟随标志。
- `CategoryOverview.jsx` / `categoryGallery.js`：六类使用连续横滑的 2.5D 产品投影。一类主景、相邻远景与实时三维展台共同呈现；用户已明确换回原来六张清晰展厅图片。`featured-categories.json` 的 `image` 用于文章，`sceneImage` 用于三维投影，黑底素材通过亮度遮罩融入空间。点击进入真实细分类文章，返回保留选择。美妆、儿童玩具、派对仍可进入已有完整三维概念场景。素材说明见 `public/media/categories/spatial-provenance.json`。
- 品类方案二的竖屏展窗与明暗色系已按用户反馈撤出当前展示；相关文件仅保留为未采用试验。旧地址中的 `categoryScheme=2` 不再启用方案二，也不改变公司首页入口。品牌图标修正独立保留。
- Koko & Milo 的总览、聚焦、介绍封面与图片放大共用 `featured-brands.json` 中的 `pdm-koko-milo-clean.png`。不再仅靠三维材质清底；原图保留为素材来源，清理记录见 `docs/koko-milo-image-cleanup.md`。
- `companyMountainWorld.js` / `CompanyEntrance.jsx`：首页采用用户于 2026-09-15 确认的原始品牌标志装置、星空与流动海面。原始矢量决定主体轮廓，图像提供表面细节，真实反射与共享水波场联动。星空和其它主题的低对比光雾由 `共享组件/spaceAtmosphere.js` 生成；动画继续使用唯一帧循环。旧公司大楼与早期山体文件仅保留历史，不在当前首页构建链中。
- `SupplyNetwork.jsx` / `supplyWorld.js`：仅平面世界地图，已移除球形入口、地球模型和投影切换。点击中国、柬埔寨、美国放大进入已预热的三维地区场景；越南入口展示供应商覆盖，不借用其它国家的工厂模型；返回保留缩放、筛选和选中国家。球形与平面叠影的旧问题随球形路径撤出，不再单独优化。
- `chinaDevelopment.js` / `supplyRegionsContent.js`：中国为研发与核心供应链，包含材料、设计、打样、核心供应链四个空间。柬埔寨提供制造协同，保留生产、质量、交付三个工厂空间；美国为市场与客户协作。地区模型为概念演绎，未声明实际场地产能。
- `supplyDepth.js` / `ImpactTheatre.jsx`：场景预构建并预热，进入或返回不新建模型及渲染器。唯一帧循环管理转场、运动、巡展和资源释放。手动输入停止跨主题巡展，但保持环境动画；阅读和暂停遵循原有保护规则。

品牌使用门户官方标志；品类展示使用用户选择保留的原创概念图片，完整三维品类模型同样标为概念场景。主展厅仍保留原始档案和其他路由，不把概念样品冒充真实 SKU。

## 验证
