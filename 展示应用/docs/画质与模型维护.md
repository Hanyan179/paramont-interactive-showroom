# 画质与模型维护

## 当前实现

主展厅与产品模块读取同一份 `../共享组件/qualityConfig.js`，默认 `exhibition`（展厅档）。没有给访客增加画质菜单或第二套系统栏。旧 `studio`、`gallery` 实验入口不属于本次接入范围。

配置分两层：渲染参数控制整张三维画面的分辨率、抗锯齿、阴影、环境反射；模型参数控制已经制作好的曲面细分、倒角、表面细纹和局部运动。改变面数不会自动创造机械结构、真实设备或新的场景动作。现有空间均继续按“概念示意”展示。

| 档位 | 三维像素预算 | 阴影尺寸 | 曲面倍率 | 表面细纹 | 工作台底图 / 光点刷新 |
|---|---:|---:|---:|---|---|
| `fluid` 流畅 | 310 万 | 1024 | 0.8 | 关闭 | 原尺寸 / 30 次/秒 |
| `exhibition` 展厅 | 829 万 | 2048 | 1.25 | 开启 | 1.5 倍 / 60 次/秒 |
| `studio` 精修 | 1475 万 | 4096 | 1.75 | 开启 | 2 倍 / 60 次/秒 |

主展厅与产品模块都使用离屏多重采样抗锯齿，分别请求 2、4、4 次采样。纹理斜视过滤分别为 4、8、16 倍。设备能力较低时按浏览器报告的硬件上限限制，并在诊断中记录实际值；不根据短期帧率自动切换档位。

“展厅档”允许 3840×2160 原生三维渲染，解除之前两端约 270 万、310 万像素的固定限制。画布像素预算只影响三维层，正文、导航和阅读器保持浏览器自身清晰度。高档位并不承诺某台未测试电脑能稳定运行；部署时以实际硬件和连续运行记录决定档位。

## 如何调整

直接打开 `../共享组件/qualityConfig.js`，例如：

```js
export default {
  preset: 'exhibition',
  render: { shadowMapSize: 4096, maxPixels: 8294400 },
  models: {
    monument: { geometry: 1.5, surfaceStrength: 0.2 },
    china: { geometry: 1.25 },
    cambodia: { geometry: 1 },
    products: { geometry: 1.5 },
    serum: { geometry: 1.75 },
    analytics: { screenScale: 2, screenFps: 60 },
  },
};
```

省略字段继承档位；单款产品优先于 `products` 公共设置。地区参数独立，避免调整中国工作室时顺带更改柬埔寨产线。主展厅和产品是两个构建结果，**更改共享源文件后必须重新构建产品模块、导出，再构建主展厅**，不能只刷新旧的已导出产品包。

无需编辑文件即可临时比较以下本地地址；不写入访客的浏览记忆：

- `http://127.0.0.1:5183/?quality=fluid#/atlas/home`
- `http://127.0.0.1:5183/?quality=exhibition#/atlas/home`
- `http://127.0.0.1:5183/?quality=studio#/atlas/home`

查询参数覆盖默认档位，文件中的单项覆盖仍然生效。嵌入产品模块继承同源父展厅的档位；独立运行时读取自己的地址。切档需要重新载入页面，以完整重建几何和渲染目标，避免运行中替换一半资源。

## 参数的实际作用

| 参数 | 用途与边界 |
|---|---|
| `render.maxPixels`、`maxDpr` | 三维像素预算和设备像素倍率上限；支持非 16:9 屏幕 |
| `render.shadows`、`shadowMapSize` | 两端主光阴影开关和分辨率；512–4096，取不超过设置值的 2 的幂 |
| `render.msaa` | 离屏抗锯齿采样数，0–8，按设备能力限制 |
| `render.anisotropy` | 斜视纹理清晰度，1–16，按设备能力限制 |
| `render.ao`、`aoScale`、`aoSamples` | 主展厅区域近景接触阴影；产品模块没有这一后期效果 |
| `render.bloom` | 主展厅发光强度，0–0.5；保留地区切入时的原有减弱关系，不影响产品模块 |
| `render.exposure`、`environment` | 两端曝光和环境反射；反射按原场景强度乘算，保留材质与主次关系 |
| `render.transmissionScale` | 透射材质的渲染分辨率，作用于精华瓶等玻璃材质；不是反射精度 |
| `models.<id>.geometry` | 曲面、轮廓和倒角细分倍率，0.5–2；圆角最多 6 段、倒角最多 8 段。直线、六角铅笔等设计结构不盲目细分 |
| `surfaceDetail`、`surfaceStrength`、`textureSize` | 金属拉丝、涂层细纹及产品细密压纹开关、纹理起伏强度和程序纹理尺寸。地球开关作用于原有法线细节，不换地理贴图 |
| `screenScale`、`screenFps` | 前者作用于工作台、刊物、产品标签的自绘贴图；后者仅作用于分析工作台的流动光点；文字与连线仅在内容变化时重绘。不会缩放正文或修改影片帧率 |
| `motionScale` | 现有局部持续运动的速度倍率，0.25–1.5；不改变触摸灵敏度、镜头转场和巡展停留时间。静态模型不凭此产生新动作 |

非法数值会限制到范围内并记录警告；未知模型名不会悄悄创建场景。主光位置、玻璃厚度、颜色、造型比例与具体动作仍由模型工厂维护，不能用统一倍率代替美术设计。

## 各模型的角色与维护入口

| 配置标识 | 展示角色、动作 | 几何/材质入口 |
|---|---|---|
| `monument` | 山形镂空品牌装置；环绕总览、点击固定机位、克制呼吸光 | `BrandMonument.js` |
| `story` | 创意形成、协作连接、时间生长；保持每章自己的结构变化 | `HomeStoryWorld.js` |
| `globe` | 全球地点与产品流；旋转、选择、切入地区 | `ConnectedScene.jsx`、`rendering/EarthSurface.js` |
| `samples` | 首页样品工作台；与其他主角保持环绕间距 | `ConnectedOverviewWorld.js` |
| `china` | 错层创研、研究拱架、样品开发与分层原型运动 | `CapabilityWorld.js`、`LocationArchitecture.js`、`LocationScenery.js` |
| `cambodia` | 产线、检测、仓储；传送、机械臂、扫描与交付动作 | 同上 |
| `usa` | 会谈、市场陈列和团队工作空间 | 同上 |
| `news` | 电视与刊物；切近景后自然进入影片或阅读器 | `MediaExhibits.js`、`CompanyNewsWorld.js` |
| `analytics` | 单一分析工作台；屏幕呈现信号、品类、智能关系和产品方向，镜头切入图形 | `DataWorkstation.js`、`analytics/AnalysisInstrument.js` |
| `products` 与八个单款标识 | 口红、精华瓶、粉盒、套圈、沙锤、拼图、气球、礼盒；保留单主角、款式、观察和返回 | `../品牌融合世界/src/models.js`、`scene.js` |

欧洲、澳洲仍是待资料确认的市场区域，尚无独立三维空间，因此未设置假模型档位。已有媒体图片不会因提高纹理尺寸获得原文件没有的细节。岩石旧案和 `IntelligenceSculpture.js` 均非本轮主场景的精修对象。

## 后续新增模型

1. 先定义角色、轮廓、近景细节和动作目的，再制作模型。保持一处视觉重点。
2. 在 `renderQuality.js` 的 `MODEL_IDS` 注册标识；在 `qualityConfig.js` 中增加可维护覆盖项。
3. 工厂使用 `modelDetail(id)` 读取配置，将 `segment()` 接到真实几何参数。需要自绘贴图时接入 `screenScale`；只有实际存在持续运动时才使用 `motionScale`。
4. 程序表面纹理通过 `surfaceFinish.js` 创建，独占资源随模型释放；不增加第二套帧循环。
5. 沿用现有 `root/update/pick/bounds`、固定机位和返回状态。画质档位不改变业务信息、碰撞目标和触摸规则。
6. 比较三档的轮廓、材质和局部动作，并检查进入、返回、暂停和中英文。通过后重新构建两端。

官方依据：[Three.js 渲染器参数](https://threejs.org/docs/pages/WebGLRenderer.html)、[物理材质](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[光源阴影](https://threejs.org/docs/pages/LightShadow.html)。当前项目使用本地锁定版本，实际可用参数以该版本源码和运行验证为准。
