# 首页与触摸回归记录

验证日期：2026-09-11。当前修复仅针对全局首页返回与三维热点的点按/拖动，未专项修复此前报告的“供应链局部返回地球后模型残留”。

## 修复

- 底栏标志、区域菜单的公司介绍、文档阅读器与新闻播放器中的首页入口统一调用 returnHome，目标固定为 atlas/home 的 chapter 0。
- 全局首页关闭当前阅读器、影片、样品、地点详情与分析近景，取消未完成的关闭计时器和巡展恢复。产品模块内部浏览状态继续保留。
- 模型热点与画布共享同一套指针事件。鼠标、触摸和笔输入采用一致阈值；拖动或取消不生成点击，兼容 click 事件不会造成重复选择，键盘激活不被拦截。
- 首页保持整圈自由观察。手动点选仍按已有机制切入固定展示机位。

## 浏览器实测

在 5183 本地服务、最高精修档中实际操作：

| 操作 | 结果 |
| --- | --- |
| 从模型表面与模型热点开始横向拖动 | 观察角发生变化；首页章节仍为 0，无误选或误进入 |
| 单次点击公司热点 | 仅选中公司介绍，再点击进入按钮才进入正文 |
| 公司正文 → 文档 → 首页 | 关闭文档，回到总览，无选中模型 |
| 全球布局 → 柬埔寨 → 供应链与交付 → 首页 | 回到总览，清除能力面板和当前聚焦 |
| 数据工作台 → 分析案例 → 首页 | 分析层关闭，恢复首页模型与导航 |
| 品牌与产品 → 首页 → 拖动 | 产品层关闭，主画布恢复可拖动，画布保持一份 |
| 公司动态 → 放映室 → 首页 | 关闭放映室，影片停止，回到总览 |
| 30 秒静置后的首次输入 | 只唤醒，下一次输入操作内容 |

返回后观察到单一系统栏、chapter 0、无活动对话框；精修档参数保留。浏览器日志未出现本轮运行错误。
