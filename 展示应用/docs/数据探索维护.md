# 数据探索维护

当前本地入口：`/#/atlas/analytics`。参考依据为 `../设计资料/2026-09-11_数据探索参考/数据分析区参考与交互建议.md`。

## 当前体验

以“下一季儿童创意用品”为一个连贯的设计案例。点击三维工作台后镜头接近屏幕，进入国际趋势、品类矩阵、人工智能协同、产品方向四段。四段沿用相同的主题和市场选择；资料在统一阅读器中打开。

当前为设计示例，没有执行在线人工智能分析，也没有已验证的市场规模、增长率、消费者原文或市场比较。市场选择表示拟研究范围，不改变未经验证的图表权重。关系线等宽，不编码数量。正式资料补齐前保持这些说明。

## 补真实案例

1. 原始报告、日期、市场范围、原文与使用图片保留在 `../素材收集/06_数据分析案例/`。目录不会自动同步；确认可展示范围后再整理展示文案。
2. 在案例中维护双语来源、问题、归类理由、验证状态和图片说明。关系图与三维屏幕共用同一组节点和关系，不能各维护一份事实。
3. 每个主题维护使用情境、产品形态、材料语言三个维度。新增维度或新增主题时同步调整图形布局；超过当前三条线索不要直接堆入画面。
4. `productId` 与 `skuId` 必须同属已有概念档案。当前共同玩耍关联 `puzzle/puzzle-01`，形状与触感关联 `rings/rings-02`，随行创作暂不关联。无映射、错误映射或资料未加载时不打开默认商品。
5. `studyDocument` 按所选主题和市场生成资料身份。来源、设计解释、归类理由、人工复核各有稳定章节标识；右上箭头仅打开对应文档。
6. 使用原有阅读器的图片浏览、阅读时间估算、双语章节恢复和暂停巡展能力。产品业务仍由嵌入模块负责，不在数据区重建。

## 生命周期

工作台使用现有共享帧循环；屏幕绘制限制为每秒最多 15 次。接近屏幕结束后由网页图表接管，物理模型退出可见渲染；返回先显示同一物理屏幕，再拉回原位。页面隐藏或阅读文档时暂停图表动画。无新增空闲计时器。

沿用 30 秒静置、90 秒巡展。静置时说明与操作渐隐、图形放大；完整巡展的数据四段使用同一条“形状与触感”线索。触摸唤醒恢复访客原先的阶段、主题、维度和市场。

## 验证

运行项目已有测试、内容检查、本地构建。改嵌入模块时先构建并导出产品模块，再构建主展厅。浏览器重点走通主题选择、关系线点击、矩阵比较、资料章节、图片放大、切换语言、精确样品进入与返回；检查小尺寸、全高清、超高清与较窄桌面比例。现场触摸与连续展示仍需实机验收。
