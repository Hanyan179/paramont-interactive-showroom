# 广告屏发布接入

在线企业展厅读取 DSR（数字样品房）的已发布精选资料，不再默认读取前端归档作为当前品牌、品类和产品数据。配置入口为 `/v/admin/sample-room-advertising-config`；公开观看入口为 `/enterprise-showroom/`。

## 运行与构建

- 仓库根目录运行 `npm test`、`npm run build`。构建仍先生成嵌入模块，再生成主展厅。
- 本地沿用端口 5183；`WORKBASE_DEV_ORIGIN` 指定本地 DSR 后端地址，默认 `http://127.0.0.1:14310`。`/api`、`/v`、`/static` 代理到该地址，便于同源预览。不要把本地开发代理当作生产网关。
- 默认在线构建通过 `GET /api/sampleAdvertisingPublic:get` 获取快照，通过 `GET /api/sampleAdvertisingPublic:asset?id=...` 读取已发布素材。不传上游凭证，不查询任意产品。
- 没有发布、读取失败时显示真实错误，不补入旧归档。更新资料须先在后台预览并发布，大屏刷新后生效。
- 独立离线演示需显式设置 `VITE_ADVERTISING_STANDALONE=1`；`npm run package:windows` 已通过独立构建脚本设置该变量。离线归档不代表实时业务。本轮没有执行 Windows（视窗系统）安装及现场设备验收。

## 资料与导航

公司文档、章节、品牌标识和介绍由后台维护；品牌、品类及精选产品的关联以 PDM（产品数据管理）的编号为准。品牌选择不自动公开其全部产品，当前计数仅为发布选入数量。上游产品主数据不可在展厅修改。

供应链继续使用标有来源日期的国家分布快照；智能与三维内容保留概念标识，不能宣称实时 MDM（主数据管理）接通。未匹配到上游的品牌不猜测关联。

所有主入口集中到右侧居中可展开导航。地图缩放位于左侧中部，避免与导航重叠；原有筛选、目录和缩放能力保留。打开菜单暂停巡展，Escape 关闭并恢复焦点；阅读返回、选中品类和地图上下文保留。

## 部署边界

静态站点和 DSR 后端必须配套发布并记录两个提交。生产网关使用 DSR 仓库的 `deploy/workbase/enterprise-showroom.locations.conf`：壳和必要编译、概念素材可读取；历史 `/data/`、`/modules/` 及其他未批准素材保留登录保护。上传文件经发布引用接口读取，不能直接暴露后台私有存储。

完整预览只接受同源父页面消息，传递展示快照和临时素材地址，不传会话。浏览器尺寸检查不能代替现场站立触摸验收。
