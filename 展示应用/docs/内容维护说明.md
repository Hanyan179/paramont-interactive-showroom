# 内容维护说明

## 用户维护的资料

原始资料目录在 `企业交互展厅/素材收集/`。沿用 00–07 的中文目录和填写说明。不要为了展示页面覆盖原始照片、标志或报告。

目前优先补充：三个国家对应的城市、具体场地、团队介绍和可展示的项目案例；真实品牌样品图；公司介绍与数据分析案例。未确认的业绩、产能、客户关系保持空缺。

## 展示清单

`public/data/showroom.json` 是当前样稿的本地内容入口，首次载入时读取。修改后刷新页面。构建交付时重新执行 `npm run build`。

- `settings.idleSeconds`：空闲自动展示时间，默认 90。
- `settings.slideSeconds`：自动展示章节间隔，默认 12。
- `locations`：国家名称、经纬度、城市、业务类型、介绍和媒体。目前经纬度仅为国家层面的交互示意，不是厂址。
- `brands`：真实品牌名称、双语简述、标志、概念配图、氛围颜色。
- `samples`：样品编号、所属品牌、品类、双语名称、图片、可选视频。
- `categories`：品类筛选。当前样稿展示 4 类概念样品；用户工作簿的完整品类档案在 `catalog.json`，暂未建立档案品类与概念样品的对应关系。

名称、品牌说明使用 `[中文, English]` 数组。地点的 city、type、description 可使用同样的双语数组，当前组件也支持单语字符串和空值。不能把机器翻译当成已确认公司说法。

展示图放 `public/media/generated/`；真实资料加工后建议另建 `public/media/company/`，并在内容清单中明确素材类型。`asset()` 当前将样品图片解析到 `generated/`，接入真实素材时同时更新路径解析和概念标注。不能仅替换文件便继续保留错误归属。

地点媒体示例：

```json
{"type":"video","src":"/media/company/site-film.mp4","alt":"经确认的现场视频"}
```

## 事实与概念的边界

官方品牌名称和简述来自官网。当前样品的品牌归属用于交互演示，不代表真实商品目录，界面已标明“概念样品”。地球连线表达概念上的协作关系，不代表物流线路、合同关系或实际出货。

山峰场景是品牌叙事，来自经过许可的通用岩体模型与自建场景，不是公司实际园区。上线展示前，由公司确认真实文案、品牌归属、数据与展示范围。

## 品牌与品类工作簿

原始工作簿只读保留在 `素材收集/04_品牌能力/2026.9.10 存档.xlsx`。当前提取 67 条品牌档案（含 1 条 Undefined）、18 个大类、327 个细分类。Undefined 保留为待定义记录，不进入精选品牌画廊。档案数量不是自有品牌数量。

更新原始资料后，由我运行 `scripts/import-catalog.py`，生成 `public/data/catalog.json`。生成清单保存原文件名、SHA-256 校验值、来源工作表、范围和每条记录的行号。原始编码（包括前导零）和英文拼写保持不变；大类中文名为展示翻译。档案没有品牌归属和品牌—品类关系，因此系统不会推断它们。

5 个精选品牌继续使用官网确认的标志与简介。只有名称严格归一化后对应的档案才显示这些已有内容；其他品牌采用名称排版并说明介绍、标志、真实产品待补充。

## 工厂能力与影像

三地业务分工由用户于 2026-09-10 确认：中国是创意、设计、研发与研究的源头；美国负责销售市场、客户和当地团队；柬埔寨负责工厂、加工制造与供应链。地球分别连接中国的开放创研岛、美国的弧形会客展厅、柬埔寨的贯通工业厂房剖面，各有三处可深入的空间。建筑轮廓、室内物件、章节文案与展点按国家独立组织，章节点选控制镜头和动画。它们是概念空间，不代表真实场地、设备或规模。`concept-factory-campus.png` 保留作设计参考，不再作为能力页背景。地点 `media` 显示在“空间总览”的玻璃资料面板中，点击放大图片或播放视频，不替换三维环境。

`locations[].capabilities.manufacturing`、`quality`、`delivery` 可各自维护双语 `title`、`description`、`items`，每条 item 包含双语 `name` 和 `description`。描述显示在所属场景的面板中，items 经展点的“相关资料”入口继续展开；没有资料时明确显示待补充状态。内部键名为兼容现有章节点位而保留，含义依国家不同：中国依次为设计、研究、研发，美国依次为市场、客户、团队，柬埔寨依次为制造、检查、交付。五阶段集团质量框架只在柬埔寨的质量展点显示，仍不声明当地具备全部能力。

## 公司介绍

首页的定位、能力、协作公司、历程读取官网采集的 `official-content.json`，展示文案在 `CompanyStory.jsx` 组织。后续新增公司、年份或能力时同时维护双语文案，检查对应关系。项目当前没有后台和自动翻译服务。

## 空间与交互维护

- `src/components/locationProfiles.js`：按国家维护业务定位、三处空间的章节名称、双语说明、展点与概念样品关联。
- `src/components/capabilityContent.js`：共享的几何锚点与原质量框架，国家文案以 locationProfiles 为准。
- `src/components/CapabilityWorld.js`：国家场景选择、相机、材质与动画控制。射线点击只读取当前国家的展品。
- `src/components/LocationArchitecture.js`：三地独立的建筑轮廓、承台、顶棚和结构；不再共用三间并排方框展馆。
- `src/components/LocationScenery.js`：中国研究与研发、美国市场与团队、柬埔寨加工等室内物件。真实场景准备好后可替换几何，保留章节点位与内容层。
- `src/components/ConnectedScene.jsx`：地球进入/返回、相机渐进变化、场景渲染、展点投影与遮挡保护。
- `src/components/FactoryDetail.jsx`：玻璃阅读层、质量阶段、样品入口、实际地点媒体。
- 现场页面不显示手势教学；目录中的使用说明继续保留。原始资料与展示资源分开维护。

## 首页章节与三维叙事

首页选择状态由 `App.jsx` 统一管理，`CompanyStory.jsx` 与 `ConnectedScene.jsx` 共用能力、公司、年份和展点选择。切换至全球布局再返回时保留这些选择。

- `src/components/homeStoryContent.js`：序章三个主题、四类能力的子展点、双语说明、公司节点和六个年份。数据来自既有官网采集资料；新增年份时同时调整几何分组，不能只追加数组。
- `src/components/HomeStoryWorld.js`：三峰层叠雕塑、开发分层、质量环、洞察阵列、公司协作节点与逐年构筑。均为抽象品牌叙事，不代表真实设备、产能或厂区。
- `src/home-story.css`：首页阅读区、细节展开、时间轴和展点的安全空间。选中细节时缩小标题区，优先完整展示新内容。
- 主要入口有稳定的左侧等价按钮；三维展点在转动时避让正文和其他标签，选中展点优先。构件本身也有射线点击选择。

品牌世界本轮不调整、不做界面验收；其他任务的产品模块接入改动予以保留。

## 四区版本更新（覆盖上文过时范围）

主产品现在只有公司介绍、工厂能力、品牌与产品、数据分析四区。品牌和品类已合并为产品模块的内部目录，本轮允许并检查必要的整合交互；不再保留独立的“品牌世界”主入口。主系统没有视觉方案选择。

- `src/components/DataStory.jsx` 的 `analysisSteps`：四阶段双语流程及说明，均为概念内容；实际报告请放 `../素材收集/06_数据分析案例/`，包含客户问题、过程、结论、来源与可展示范围，由我整理接入。
- `src/components/DataWorkstation.js`：首页缩略电脑与数据区完整工作站共用的三维几何；屏幕图形是示意，不能当成真实统计值。
- `../共享组件/flowSky.js`：两个项目共用的星尘与慢速流光，不读取业务数据。
- 欧洲办事处先不创建正式场地点位；请在项目/设备资料中补充国家、城市、业务角色和可展示的事实，确认后再更新地点清单及内部空间。
- 商品流向仅表达国际流通方向。当前路径位于 ConnectedScene 的 `destinations`，不能据此推断真实订单或客户所在地；以后接入真实流向需补充来源、时间范围、粒度与公开权限。
