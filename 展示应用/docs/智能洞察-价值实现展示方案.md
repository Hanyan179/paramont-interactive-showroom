# 智能与洞察：总览与价值实现的三个候选方案

2026-09-19 · 三个候选的首轮实时三维预览已实现，保留并行比较。旧方案源文件及原始素材保留。

## 先确定要表达的业务

本次观众是进入公司展厅的客户与合作伙伴。希望他们看懂：公司能够把外部信息、行业研究与专家经验，转化为有依据的产品和市场行动，并从反馈中继续改进。

现有实现的问题已经确认：总览将三组品类示意图放在平面几何上，围绕地球展示；价值实现阶段复用地球，而案例正文主要讲概念样品验证。图像、地球和业务结果之间缺少可见的因果关系。继续提高球面精度或增加轨道，无法补上这段关系。

**共同叙事：发现一个需要 → 比较可行方向 → 作出选择 → 形成产品或选品方案 → 验证是否满足需要 → 将反馈归入知识。**

产品成形只是中间状态。价值实现还需要说明它改善了哪件事，以及通过什么反馈判断改善是否成立。可以展示的结果包括需求与方案更匹配、开发取舍更明确、客户选品得以推进；打样轮次、确认周期、订单或复购等经营结果，需要真实记录支持后再展示。

三个方案使用同一条业务链比较，区别在于让什么成为主角。现有六阶段入口、总览—阶段详情—业务案例的三级关系继续保留；供应链地图不在本次重做范围内。

| 方案 | 视觉主角 | 核心业务问题 | 最适合的展示目的 | 主要依赖 |
| --- | --- | --- | --- | --- |
| A · 洞察塑造一个产品 | 一件可近看、可操作的公司产品 | 这个产品为什么这样设计？ | 让观众看到洞察如何改变产品 | 选定样品、多角度参考、尺寸与结构依据 |
| B · 从全球信息到市场选择 | 一颗有明确业务含义的精致地球 | 哪个市场的什么需要，值得响应？ | 表达跨市场研究与机会判断 | 可追溯的区域资料、比较维度与案例 |
| C · 从机会到客户选品 | 一套有取舍关系的立体产品组合 | 为什么给这个客户推荐这一组？ | 表达面向客户的开发与选品能力 | 同系列样品、组合依据、客户需求案例 |

## A · 洞察塑造一个产品

**建议优先探索。** 一个足够精致、具有使用动作的实物主角，能够同时承载产品身份、设计理由与动态过程。

### 总览怎样呈现

画面保留当前深色星空和安静的文字区，主体是一件完整产品，占据明确的视觉中心。产品使用自身真实颜色和材质，银蓝光只用于轮廓和信息提示。没有围绕主体悬挂的品类图片。

先从现有样品中选择一件有开合、组合或取放动作的产品。用于讨论的假设案例是“便携创作套装”：主体有盒体、内托、工具和明确的收纳关系。它尚未被确认是公司的具体在售产品，不直接作为生产素材。

无人操作时，主体缓缓调整观看角度；某个功能结构短暂打开，展示真实使用关系，然后合上。一次只出现一句与动作有关的提示，例如“让创作，也方便收纳”。字幕必须由案例证据或明确的设计假设支撑。

### 决策怎样进入价值实现

1. 决策阶段已经选中的方向继续保留。若案例的决策重点是便携收纳，镜头就跟随这个明确的需求进入产品结构。
2. 产品的内托、工具和盒盖按真实装配关系就位，镜头接近被改变的细节。标签说明“为什么这样设计”，例如取放顺序或工具固定方式。
3. 产品完成一次简短的使用动作，展示设计如何响应需要。只做与案例有关的结构变化，不把完整产品全部拆散炫技。
4. 进入样品或客户评审状态：显示一条真实反馈及对应修订；没有真实记录时，显示“待验证问题”，不自动出现已验证或成功标识。
5. 这一条反馈被收进下一阶段的知识档案，保留与产品、来源和决策的对应关系。

### “价值”具体落在哪里

让观众看到某个需求如何改变了产品，而团队如何判断这种改变有没有用。落到案例页，可呈现需求依据、设计取舍、样品版本和评审记录；有真实数据后，才补充迭代轮次或客户确认等结果。

### 精致感怎么取得

重点打磨真实比例、曲面与倒角、接缝、壁厚、透明件厚度、印刷位置、材料粗糙度和接触阴影。产品转到侧面仍有正确体积，打开后内部关系仍成立。

几何负责轮廓与结构，照片可用于真实表面纹理、印刷和案例资料。产品的几何精度不能靠一张正面图替代。真实颜色也不应被统一涂成蓝色玻璃。

**风险与边界：** 没有选定样品及结构资料时，只能制作标注为概念的样机；不能承诺产品级还原。优先选资料完整、轮廓有辨识度的硬质或半透明产品，首轮不同时挑战复杂软体、毛发和大量零件。

## B · 从全球信息到市场选择

**保留地球方案，但让地球承担研究对象的含义。** 它表达不同市场中的信息、需求与机会。供应链页已有国家覆盖和协作网络，这里需要清楚地展示研究和决策的区别。

### 总览怎样呈现

一颗精致、低速转动或有限摆转的地球为唯一主角。采用有层次的海陆材质与克制的大气边缘光，不增加围绕地球的产品贴片。

少量区域信号先后出现，只有被选中的研究主题保留。信号附近显示简短且可追溯的主题，如“使用情境”或“渠道偏好”；有具体市场结论时，必须绑定来源和日期。避免用城市灯光密度或随机热区暗示未经验证的市场规模。

### 洞察、决策、价值怎样连接

1. 一个研究主题在两个或三个有资料依据的区域中展开。用户可固定一个区域，查看其依据。
2. 选中主题的信号增强，周围无关信息渐弱，表现机会从信息中被识别出来。
3. 固定位置的界面给出候选行动及取舍。业务人员选择需要验证的产品方向或区域版本；地球不代替这一步判断。
4. 镜头移向一个真实三维产品或产品版本。地球缩到背景，仍保留选中区域。只呈现与所选市场需求有关的一处版本差异，如组合内容、包装结构或展示方式，具体差异由真实案例确定。
5. 客户评审、试销或其他已授权反馈返回相应区域，并进入知识档案。无实绩时停留在验证计划，不点亮“市场成功”。

### “价值”具体落在哪里

信息帮助团队决定在哪里验证什么产品、为什么作这样的调整。案例页给出区域依据、行动选择和反馈记录，观众能够沿同一条关系返回来源。

**动态特点：** 区域信号具有来路和去向；镜头与焦点连续变化。只保留少量可理解的光流，不再堆航线、飞机、货轮或产品卫星。

**风险与边界：** 若缺少区域研究依据，地球会再次变成装饰，并与全球供应链页面重复。这个方案只在“全球市场判断”是核心展示目标时优先；产品仍需可靠的三维资产，不能靠地球遮掩素材不足。

## C · 从机会到客户选品

**适合突出公司面向客户的产品开发与组合能力。** 主角是一套完整的产品提案，观众能看见选入、替换和收敛的理由。

### 总览怎样呈现

三到五件属于同一主题的真实三维产品，形成一组有前后层次的陈列。只有一件主产品突出，其余承担补充角色。构图像精心布置的产品展陈，避免变成图片卡片墙或杂乱品类集合。

主题来自一个明确的客户或使用需要。真实客户身份、标识和商业记录须在获准展示后使用；提案阶段可用明确标注的假设场景。

### 决策怎样进入价值实现

1. 决策阶段的选品条件继续保留，例如使用场景、开发约束和展示要求；不填虚构价格、销量或评分。
2. 候选产品逐个进入同一陈列空间。被选入的产品获得稳定位置，未入选方向退到背景，并可查看取舍理由。
3. 组合收敛为一套可以讨论、打样和提交客户的方案。包装与使用关系完整可见，镜头重点展示组合的互补关系。
4. 一条客户或团队评审意见引发一次明确变化：替换一件、调整配色，或改变组合方式。保留版本前后的对应关系。
5. 形成提案与样品评审记录，反馈进入知识档案，为下一次选品提供依据。

### “价值”具体落在哪里

把研究结论变成客户能够选择的方案，并让选品理由、评审和修订可追溯。若有真实记录，可进一步展示客户确认、样品采纳和复购等结果；提交提案本身不代表已成交。

**动态特点：** 移动体现加入、替换和收敛，局部开合体现产品功能。每个动作都改变观众对方案的理解，不安排无意义的漂浮物。

**风险与边界：** 所需产品资产最多；不同产品的材质、灯光和精度必须一致。首轮只选一个主题的小组合，不扩成完整产品目录。

## 三个方案共用的展示与交互标准

- 总览只呈现一个清楚的业务主角，不合并堆叠六个阶段。左侧一句话解释本次正在发生什么，保留探索入口；进入后由底部固定导航切换六个阶段，总览不再重复显示阶段栏。
- 用户选阶段后停留探索，主体继续局部活动；查看案例进入依据与结果，返回保留刚才选择。暂停和减少动态偏好继续生效。
- 变化过程中保留同一个主题、选中对象或反馈标记，使观众知道后一阶段由前一阶段产生。先证明业务与视觉连续，再决定哪些形变需要真正共享网格；不强行把地球融成产品。
- 主体有真实体积、侧面和局部结构。灯光移动时反射、遮挡和阴影一致，文字和按钮不跟着模型漂移。
- 维持现有深色星空和统一操作按钮。画面强度由精细材质、近景细节和有节奏的动作提供，不用增加光线数量替代精度。
- 示例、待验证判断与实际结果分开标注。不展示没有依据的市场增幅、排名、订单或实时接入状态。

## 建议的取舍与下一步

建议先验证 **A 的精致产品主体**，同时保留 **B 的地球叙事**作为可比较候选；C 可优先用于具体业务案例，若客户选品是主要演示任务，再提升为总览主角。三个方向不同时塞进一张总览。

首轮按已获授权的概念假设制作：便携创作套装及其桌面组合，不等待真实样品资料。后续如需还原具体在售产品，再补充多角度参考、尺寸、需求依据及评审记录。

后续每个获准制作的候选先做一段相同观看条件下的短演示，重点覆盖“选择 → 产品/组合变化 → 验证与反馈”，不先铺满六个阶段。使用同一分辨率、背景和字体比较，避免被不同布景干扰判断。

第一轮评审只看四件事：

1. 不先讲解，观众能否说出当前业务问题、作出的选择和变化结果？
2. 产品近看与转侧面是否仍可信，能否指出结构和材质，而不只是看到一张图？
3. 动效是否对应一个业务动作，停下来后是否仍能理解内容？
4. 每项结果能否追溯到记录，或清楚识别为待验证的演示？

确定保留方案后，先替换正式入口并检查六阶段往返、暂停、资源释放和屏幕尺寸，再删除未选方案的独占代码和资产。背景、按钮、共享交互及其他页面引用的资源继续保留。
