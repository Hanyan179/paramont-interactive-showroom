# PARAMONT 品牌与产品探索模块 · v0.3

以用户认可的深蓝三维产品剧场为基础，仅展示品牌、品类、产品三块。它是完整企业展厅中的一个可复用模块；公司介绍、全球布局、工厂、历程与合作案例由主展厅负责；本模块不提供这些页面或官网跳转。

## 直接体验

- 独立入口：http://127.0.0.1:5208/
- 已接入的主展厅：http://127.0.0.1:5178/#/atlas/products
- 图片产品示例：http://127.0.0.1:5208/#/party/gift

主展厅的“产品探索”打开全屏模块。模块左上角“返回企业展厅”恢复原来的主展厅章节；再次进入保留模块内产品、筛选、转角、图片角度和放大状态。模块文件已经复制到主展厅自己的本地目录，因此 5178 不依赖 5208 服务。

## 当前可用内容

| 层次 | 内容与关系依据 |
| --- | --- |
| 品牌 | 5 个精选品牌，展示官方标志、品牌介绍与三组品牌特点；另有完整 67 条原表品牌档案，可搜索和切换列表/画廊 |
| 品类 | 原表 18 个大类、327 个细分类；跨全部分类搜索，逐级深入，回到原搜索结果 |
| 产品 | 8 个原创概念产品、14 个具体款式；彩环、唇色与礼盒各 3 款，其他各 1 款；礼盒全部使用图片与短片 |

所有样品都是概念，不是实际型号。67 条品牌档案不代表自有品牌、授权品牌或合作方名单。尚无证据的品牌—产品关系保持为空，因此品牌页不会把独立概念样品冒充该品牌产品。

## 产品层级

品牌承载介绍，品类提供分类入口，产品下面呈现具体款式。品类是筛选维度，不要求先选品牌才能看产品。品牌没有已验证的产品关系时，仅呈现有依据的品牌介绍，不把独立概念挂到真实品牌下面。

`product-skus.json` 中每个款式只关联一个现有 `productId`，并有独立的配色、概念编号、媒介与设计设定。当前所有 `STUDY-*` 编号都是演示编号，不是实际商品编号。

- 直接体验彩环配色：`#/play/rings/rings-02`。
- 搜索 `STUDY-GF-02` 可定位礼盒产品并直接选中绯粉银缎款。
- 切换新款式延续当前可用媒介；回到已看过的款式，恢复其图片角度、缩放与信息标签。

## 交互

- 产品目录支持横向拖动、翻页按钮、品类筛选，以及产品名称和款式编号搜索。
- 首页与领域保留三维材质、灯光、浮动构图和直接点选。
- 鼠标和触摸均可旋转场景，双指缩放模型。
- 图片有多角度缩略图、放大/缩小、复位、双指缩放与单指移动；各产品、各角度独立记忆。
- 仅呈现当前产品实际具备的媒介入口；没有模型的产品不出现空的三维标签。
- 详情返回恢复领域、筛选、场景转角；从目录进入产品再返回，恢复原目录状态。
- 中英文切换；自动展示可手动启动，90 秒无操作自动启动，触摸退出恢复原位置。播放视频、打开资料层或被主展厅收起时不触发。
- 资料层打开和模块被收起时暂停背景三维绘制，降低大屏运行负担。

## 本地使用与开发

双击 `启动展厅.command` 即可运行已有离线包。运行电脑需 Node.js 20.19 或更新版本；无互联网也能使用。本项目不包含后台或数据库。

```sh
npm ci
npm run dev
npm run check
npm run build
npm run export:module
```

本机 5208 已有静态服务时，开发预览可用 `npm run dev -- --port 5209`，不要占用已有主展厅端口。macOS 上本机自带 Node.js 存在原生依赖签名限制时，两个 `.command` 启动文件会优先使用已验证的 Codex 内置 Node.js。

`更新离线包.command` 先校验数据，重建本模块，再更新相邻 5178 主展厅中已接入的模块快照。其他项目使用 [接入说明](integration/README.md) 中的组件与导出方式。

## 共享资料和维护

开发阶段读取相邻 `../共享数据/`，不在前端编造或复制一套新的品牌事实。

| 共享文件 | 用途 |
| --- | --- |
| catalog.json | 67 / 18 / 327 原表记录和来源行号；链接到现有权威文件 |
| official-content.json | 共用的官网事实与品牌依据；本模块只读取品牌部分，其余供主展厅使用 |
| brand/ | 官方标志；链接到现有素材目录 |
| domains.json | 三个精选领域与原表大类的对应 |
| concepts.json | 当前 8 个原创概念及明确的品类依据，brandId 为空 |
| explorer-media.json | 每个产品默认可用的模型、图片、短片、默认媒介 |
| product-skus.json | 产品下的 14 个概念款式，含演示编号、独立配色与媒介 |

构建生成 `dist/shared/` 离线快照与 `shared-integrity.json`。维护共享资料后，各接入方更新同一模块包即可。本轮实际接入了 5178；没有改造其他前端。

`public/studies/` 保留 42 张本地角度图和 14 段旋转短片，来自本项目程序模型。旧官网图片未使用。真实产品资料到位后，需同时维护产品身份、品牌关系依据、规格与图片的真实性标识；不能只替换概念照片便当成真实产品。
