# PARAMONT 品牌融合世界

一套独立的大屏三维产品展厅，预览端口 **5208**。以深蓝品牌空间、香槟金材质和低饱和色彩连接美妆、儿童玩具与派对，不采用山峰、地图或其他品牌标志作为业务主视觉。

## 使用

- 双击 `启动展厅.command`。浏览器打开后可点击右上角「全屏」。无需互联网；运行电脑需有 Node.js 20.19+。
- 首页可直接点击三维物件，或进入底部三个领域。拖动旋转，双指缩放；详情支持正面、侧面、背面、多角度图片和短片。
- 左上角返回保留领域、旋转角度、缩放和筛选。档案支持搜索、列表/画廊和来源行查看。
- 右上角可切换中英文。底部「自动展示」循环六段场景，触摸恢复原位置；无操作 90 秒后也会进入自动展示，视频播放期间不触发。

## 开发和共享数据

本方案只维护自己的 `src/`、`public/studies/` 和构建输出 `dist/`。其他展厅不被覆盖。

```sh
npm ci
npm run dev
npm run check
npm run build
node scripts/serve.mjs --port 5208
```

开发运行直接读取相邻的 `../共享数据/`：

| 文件 | 用途 |
| --- | --- |
| catalog.json | 67 条品牌档案、18 个大类、327 个细分类及原表行号 |
| official-content.json | 公司事实、公司关系、历程及原始来源 |
| brand/ | 官方公司标志 |
| domains.json | 展示领域及原表大类编号 |
| concepts.json | 8 条原创三维概念记录，含概念标识和原表细分类依据 |

前两个文件和标志目录使用链接读取已有权威资料，避免新增一套业务事实。领域和概念记录同样放在公共入口，其他方案可以复用；三维模型和界面设计留在本项目。

构建时将同一来源输出为 `dist/shared/` 离线快照，同时生成 `shared-integrity.json` 校验记录。修改共享数据后双击 `更新离线包.command`；其他前端各自重新构建。

## 素材及边界

`src/models.js` 中的 8 个模型为原创程序建模。`public/studies/` 中有 24 张本地角度图和 8 段旋转短片，均由同一批模型渲染。开发时打开 `/?capture=1` 可重新生成；只在开发环境开放本地保存。

概念不对应真实型号、实际材质承诺或档案品牌。品牌档案收录不代表自有、授权或合作关系。公司资料只取事实与标志，未使用旧官网图片。第三方依赖遵循其各自许可证，未复制参考网站源代码或资产。

本版没有后台、数据库或手机版。当前产品详情展示的是概念研究；真实样品、多角度实拍、规格和视频需要后续有来源的素材补充。实体大屏性能、触控驱动和观看距离还需现场验收。

验证记录见 `docs/验收记录.md`；四套方案共享接入说明见 `../共享数据/README.md`。
