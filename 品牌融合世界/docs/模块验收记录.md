## 交付结构

- `src/`：独立模块源码，品牌/品类/产品/案例资料层、图片查看器与宿主消息接口分别组织。
- `integration/`：可复用 React 接入组件和普通网页消息契约。
- `dist/`：可直接放进其他展厅静态目录的离线模块。
- `scripts/export-module.mjs`：重复导出同一模块，维护本模块自己的文件清单。
- `../共享数据/`：共用业务事实入口，原始品牌与产品关系未被擅自改写。
- 5178 的 `src/components/ProductExplorer.*` 与 `src/App.jsx`：仅接入产品探索与返回，不接管其他设计。

其他前端未在本轮接入。任意 GLB 上传、真实产品/品牌关系编辑、后台及数据库不在首版中。当前场景继续使用 8 个精选概念，新增场景产品仍需要编排构图。

## 未冒充已验证的部分

- 实体横向触屏、触摸驱动、离线现场电脑与大屏性能没有现场测试。
- 3840 × 2160 的页面布局已检查，截图工具裁切了底部，不能把该裁切图当完整 4K 视觉证据。
- 现有模型、图片和短片都是原创概念；真实产品系列、规格和品牌归属仍需公司资料。
